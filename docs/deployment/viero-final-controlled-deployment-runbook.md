- Signer state `/var/lib/viero-signer` must be `viero-signer:viero-signer` mode `0700`; agent state `/var/lib/viero` must be `viero:viero` mode `0700`. Operation and Relay SQLite files, WAL/SHM, journal and private evidence material are signer-owned, non-world-readable. Agent must not have direct signer SQLite access.
